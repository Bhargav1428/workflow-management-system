# Workflow Management System

## Project Overview

A workflow management system backend built using Nhost, Hasura GraphQL, and PostgreSQL.

## Features

- Organization management
- Workflow management
- Workflow steps
- Workflow triggers
- Workflow runs
- Workflow results
- Role-based permissions
- GraphQL API
- Editor access control

## Technology Stack

- Nhost
- Hasura GraphQL
- PostgreSQL
- GraphQL

## Workflow

Organization
→ Workflow
→ Trigger
→ Workflow Step
→ Workflow Run
→ Workflow Result

## Testing
